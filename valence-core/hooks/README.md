# 🪝 Hooks

Valence provides a collection of React hooks that make it easier to build interactive and responsive components. These hooks handle common patterns like state management, responsive behavior, and visual styling.

## Available hooks

### State management
- **[UseDisclosure](usedisclosure.md)** - Boolean state with open/close/toggle methods
- **[UseControlledList](usecontrolledlist.md)** - Array state with add/remove methods

### Responsiveness
- **[UseBreakpoint](usebreakpoint.md)** - Current device breakpoint detection
- **[UseResponsiveProps](useresponsiveprops.md)** - Resolve responsive prop values
- **[UseWindowSize](usewindowsize.md)** - Window dimensions
- **[UseElementSize](useelementsize.md)** - Element dimensions

### Styling
- **[UseColors](usecolors.md)** - Access Valence color palette
- **[UseColorScheme](usecolorscheme.md)** - Light/dark mode detection
- **[UseFloating](usefloating.md)** - CSS for floating/positioned elements

### User interaction
- **[UseDetectKeyDown](usedetectkeydown.md)** - Keyboard event detection
- **[UseTooltip](usetooltip.md)** - Tooltip positioning

### Utilities
- **[UseLockScroll](uselockscroll.md)** - Lock/unlock body scrolling
- **[UseWindowTitle](usewindowtitle.md)** - Set browser tab title
