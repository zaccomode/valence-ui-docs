# 🧱 Components

Valence provides a comprehensive set of React components for building modern user interfaces. Components are organized into categories based on their primary purpose.

## Categories

- **[🔘 Buttons](buttons/README.md)** - Interactive elements for triggering actions
- **[⌨️ Inputs](inputs/README.md)** - Form controls for data entry
- **[🖥️ Display](display/README.md)** - Components for presenting content
- **[🧩 Layout](layout/README.md)** - Structural components for page organization
- **[🗺️ Navigation](navigation/README.md)** - Components for app navigation
- **[🔼 Overlays](overlays/README.md)** - Modals, tooltips, and sheets

## Common features

All Valence components support:

- **Responsiveness** - Props can accept breakpoint-specific values
- **Theming** - Inherit styles from the ValenceProvider
- **Accessibility** - Built-in ARIA support where applicable
