# 🖥 Display

Display components are used to present content and information to users. These components are typically non-interactive or have minimal interaction.

## Available display components

### Text & typography
- **[Text](text.md)** - Markdown-compatible paragraph text
- **[Title](title.md)** - Heading text with predefined styles

### Visual elements
- **[Icon](icon.md)** - Icon wrapper component
- **[Image](image.md)** - Image display with loading states
- **[Avatar](avatar.md)** - User profile images
- **[Avatar Group](avatar-group.md)** - Stacked avatar display
- **[Color Swatch](color-swatch.md)** - Color preview element
- **[Loader](loader.md)** - Loading spinner

### Content containers
- **[Accordion](accordion.md)** - Collapsible content sections
- **[Alert](alert.md)** - Informational messages
- **[Pill](pill.md)** - Small label/tag element
- **[Spoiler](spoiler.md)** - Hideable content
- **[Stepper](stepper.md)** - Multi-step progress indicator
