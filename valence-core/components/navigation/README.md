# 🗺 Navigation

Navigation components help users move between different sections and pages of your application.

## Available navigation components

- **[App Nav](nav.md)** - The primary navigation bar for your application, typically displayed as a vertical strip on desktop or horizontal bar on mobile

## Usage with App Container

The [App Nav](nav.md) is designed to be used within the [App Container](../layout/the-appcontainer.md) component, which handles responsive layout automatically.
