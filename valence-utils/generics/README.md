# ✋ Generics

Generics are TypeScript types and interfaces that form the foundation of Valence's type system. They provide consistent prop interfaces across all components and enable features like polymorphism and event handling.

## Available generics

### Core types
- **[Global](global.md)** - Base types like `ComponentSize`, `FillVariant`, and `GenericProps`
- **[Layout](layout.md)** - Layout-related prop interfaces
- **[Grid](grid.md)** - CSS Grid prop interfaces

### Interactive
- **[Clickable](clickable.md)** - Clickable element props (links, buttons)
- **[Events](events.md)** - Event handler prop interfaces

### Specialized
- **[Overlay](overlay.md)** - Overlay/modal prop interfaces
- **[Polymorphic](polymorphic.md)** - Polymorphic component props
